## [0.1.0] - 2026-07-25

### Added

- Rolodex of skill cards with a turn animation.
- Preview panel for GIF, MP4, WebM and image files.
- Transport deck with the undo key, the stop key, the record key and the play key.
- 3D surface with Three.js: lights, shadows, key travel and pointer parallax.
- Light theme and dark theme that follow the system setting.
- Frameless window that floats above other windows.
- Global shortcut that shows and hides the window.
- Tray icon with a menu.
- Skill discovery for `SKILL.md` folders with a file watcher.
- Four adapters: `dry-run`, `command`, `cli` and `desktop`.
- Run journal with an undo action.
- Asset protocol with a path check.
- Asset scripts for the icons, the demo skills, the glTF models, the screenshots and the OG image.
- Unit tests for the frontmatter reader, the scanner, the key builder and the layout.
- Build files for macOS, Windows and Linux.
- Continuous integration workflow and release workflow.
