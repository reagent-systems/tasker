# Code of conduct

## Purpose

This project is a place to work on software. Every person is welcome.

## Rules

1. Treat other people with respect.
2. Accept a different opinion.
3. Give feedback about the work, not about the person.
4. Do not use insults, threats or sexual language.
5. Do not publish private information of another person.
6. Do not disturb the discussions of the project.

## Scope

The rules apply to every space of the project.
The spaces include issues, pull requests, discussions and any public event of the project.

## Enforcement

Report a problem to the maintainers through a private message on GitHub.
The maintainers read each report.
The maintainers answer within seven days.

The maintainers take one of these actions:

| Action          | Reason                                            |
| --------------- | ------------------------------------------------- |
| Note            | The behavior was a first small breach.            |
| Warning         | The behavior was a clear breach.                  |
| Temporary block | The behavior continued after a warning.           |
| Permanent block | The behavior was severe or the pattern continued. |

The maintainers keep the identity of the reporter private.
