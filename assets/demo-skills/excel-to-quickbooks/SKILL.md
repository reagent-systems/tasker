# Excel To QuickBooks

Copies Excel rows into QuickBooks as receipts.

## Steps

1. Open Receipts.xlsx.
2. Read each row.
3. Open QuickBooks.
4. Enter the row values.
5. Save the record.
6. Repeat until the last row.

## Checks

- The row count matches the source file.
- Each amount matches the source value.
