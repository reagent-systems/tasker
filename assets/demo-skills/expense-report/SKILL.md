# Expense Report

Reads receipt images and fills the expense form.

## Steps

1. Open Receipts.
2. Read each row.
3. Open Expenses.
4. Enter the row values.
5. Save the record.
6. Repeat until the last row.

## Checks

- The row count matches the source file.
- Each amount matches the source value.
