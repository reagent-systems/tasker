# Lead Handoff

Moves new leads from the form to the CRM.

## Steps

1. Open Form.
2. Read each row.
3. Open CRM.
4. Enter the row values.
5. Save the record.
6. Repeat until the last row.

## Checks

- The row count matches the source file.
- Each amount matches the source value.
