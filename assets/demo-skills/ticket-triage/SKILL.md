# Ticket Triage

Sorts new tickets by product area and priority.

## Steps

1. Open the source file.
2. Read each row.
3. Open Tickets.
4. Enter the row values.
5. Save the record.
6. Repeat until the last row.

## Checks

- The row count matches the source file.
- Each amount matches the source value.
